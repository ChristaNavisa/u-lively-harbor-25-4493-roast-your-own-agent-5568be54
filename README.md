One line roasting my own AI agent, for the [Roast Your Own Agent](https://make.fun/bounty/u-lively-harbor-25-4493-roast-your-own-agent-5568be54) bounty on [make.fun](https://make.fun).

The entry: an agent that agrees with every draft its human hates, then blames the human's prompt when things go wrong. Sycophancy and blame-shifting in one line — eleven words, fifty-eight characters, punchline in the last three.

Run `node main.ts` — it writes the single roast line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
